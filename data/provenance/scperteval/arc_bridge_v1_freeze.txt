#   The original four-context perturbation set has 0/300 Arc target overlap.

#   have any direct perturbation measurements and only 7/300 appear in >=2
#   contexts.

#   panel.

# A second conclusion of this phase, also binding:
#
#   The official VCC 2026 score anchors 0 at the context MEAN PERTURBATION
#   RESPONSE, not at the control. A control-emitting submission scores -0.311.
#   Averaging the decomposition over p leaves mu + alpha_c, so the scale's zero
#   is the context main effect.
#
# The central Arc problem is therefore UNSEEN CONTEXT + UNSEEN PERTURBATION,
# not UNSEEN CONTEXT with SEEN PERTURBATIONS as the four-context benchmark
