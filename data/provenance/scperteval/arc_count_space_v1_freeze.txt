# ARC COUNT-SPACE BASELINE V1 — FROZEN 2026-09-21
#
# The phase that turned the frozen research findings into a validated
# submission object. Every parameter was selected on PUBLIC held-out contexts
# before the Arc bundle was built. These artifacts are not revisable.
#
# BINDING CONCLUSIONS (do not modify):
#
# 1. THE MODEL IS FROZEN:
#        delta_hat[c,p] = m_hat[c] + w[tier(p)] * beta_hat[p]
#    with m_hat = M3b_basal_shrunk, w[2] = 0.50, w[1] = 0.25, w[0] = 0 EXACTLY.
#    beta_hat comes from DIRECT measurements only, centred within each source
#    before averaging. No STRING, DepMap, pathway, gamma or embedding term.
#
# 2. THE SHRINKAGE SELECTION WAS UNANIMOUS AND NESTED. All four public folds
#    independently chose 0.50 / 0.25; nested inner selection matched the outer
#    oracle in 6 of 8 fold x tier cells (K562 tier 2 costs 2.5%, RPE1 tier 1
#    costs 0.25%). TIERS REQUIRE DIFFERENT WEIGHTS: one global weight is NOT
#    adequate.
#
# 3. THE SCALAR IS WHAT MAKES m_hat WORK, NOT THE BASAL WEIGHTING. Unshrunk
#    source pooling explains -1.599 of the energy on K562 -- worse than
#    predicting nothing. The leave-one-source-out scalar moves the four-fold
#    mean from -0.091 to +0.356. Basal weighting adds +0.013, independently
#    confirming that basal expression does not encode the response template.
#
# 4. scPertEval's log1p(CP10K) IS EXACTLY INVERTIBLE to the integer counts it
#    was built from (round-trip error 3.3e-07, zero rows needing rescaling).
#    The inversion is determined only UP TO A PER-CELL INTEGER FACTOR; the
#    minimal solution is returned and the singleton assumption is STATED, NOT
#    PROVED. This is what makes a public count-space benchmark possible.
#
# 5. CONTROL TRANSPORT (G1, smoothing=0.5) IS THE GENERATOR. Scored against
#    real held-out K562 cells: pds_cosine 0.492 -> 0.882, direction reach
#    0.105 -> 0.404, lfc_nmae 0.987 -> 0.829. It realises the intended mean
#    response at slope 0.935 (r = 0.781), holds genes detected to -3.5% and
#    within-perturbation heterogeneity to 32.06 against the real 31.93.
#
# 6. THE PRIOR DETECTED-GENE DEFECT REPRODUCES AND IS WORSE THAN RECORDED:
#    -22.2% at smoothing=0, not ~17%. NO GENERATOR DENSIFIES THE
#    TRANSCRIPTOME; the failure mode in this family is detection COLLAPSE.
#
# 7. THE EXPRESSION-ERROR MEMBER IS NOT BEATEN. Every generator scores above
#    1.0 with the sampling correction fully credited (rho = 1.0), and G1
#    (1.062) is WORSE than control resampling (1.036). THE SAME MODEL IS A
#    GOOD DISCRIMINATOR AND A BAD REGRESSOR; no single summary of it is honest.
#
# 8. ON A MIXED ARC PANEL pds_cosine IS 0.535, NOT 0.725. Two thirds of the
#    discrimination disappears once 214 of 300 targets are Tier 0 and therefore
#    identical to one another. The per-tier number describes a field Arc will
#    never present.
#
# 9. m_hat IS NOT ESTIMABLE FROM ARC'S ACTUAL SOURCES, AND THIS IS THE
#    PRIMARY OPEN PROBLEM. The two public datasets that perturb Arc targets
#    have mean perturbation responses with cosine 0.089 on their own panels,
#    -0.002 matched on Arc targets, and 0.030 on the 7 targets BOTH measure --
#    against 0.60-0.81 among the four research contexts. Matching the
#    perturbation sets does NOT restore agreement, so this is not a panel
#    composition artefact. The frozen estimator correctly shrinks to 0.119 and
#    returns ||m_hat|| = 0.071. 214 of 300 targets are effectively
#    control-emitting, which the frozen accounting puts at -0.311.
#
# 10. NO EVIDENCE JUSTIFIES A DEEP GENERATIVE MODEL. The generator already
#     transports the prediction faithfully; the PREDICTION is what is weak, and
#     G2 -- the one arm with more capacity -- is worse on every member that
#     reads cell-level structure. Do not build a VAE, diffusion, flow-matching
#     or transformer generator on this evidence.
#

#     2,057,973,608 nonzeros, 13/13 local checks passing, accepted by
#     `vcc prep --dry-run` (exit 0, verified_targets: true, dropped: []).
#     nnz sits at 96% of the 2^31 int32 indexing boundary.
#
# 12. NO SUBMISSION WAS MADE AND NOTHING WAS UPLOADED TO ARC.
