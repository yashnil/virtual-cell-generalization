# scPertEval datasets acquired 2026-09-20

Three additional standardized scPertEval datasets, acquired for the
unseen-perturbation phase after the Arc bridge established that the original
four contexts have **0/300** overlap with the Arc perturbation panel.

| dataset | bytes | upstream md5 | verified | Arc targets | Arc genes |
|---|---|---|---|---|---|
| `arch1` | 4,377,281,643 | `159a3576418650f47b940dca68aa0a59` | yes | 13 | 18,017 (97.2%) |
| `kaden25rpe1` | 5,641,728,720 | `bda7f3ea0173f64a0898ab6bb21a4a16` | yes | 80 | 16,828 (90.8%) |
| `wessels23` | 195,514,272 | `38bdffe5e985f2f73b671494080d4cfd` | yes | 0 | 15,439 (83.3%) |

Source: `https://storage.googleapis.com/scperteval/processed/{dataset}_processed_complete.h5ad`
Download: resumable HTTPS (`curl -C -`), upstream md5 from the bucket's
`x-goog-hash` header, compared after download. Byte sizes match
`content-length` exactly.

`arch1` and `kaden25rpe1` were explicitly approved. `wessels23` (0.2 GB) was
added so the seven-dataset coverage table could be recomputed **entirely from
local files** rather than partly from remote reads.

## Local audit

`uv run python scripts/audit_public_datasets.py` rebuilds
`public_label_inventory_v2_local.json` from the downloaded files and prints the
coverage table. Every Arc figure matches the values reported in
`reports/arc_bridge_v1.md` — per-dataset and union — so no stop condition was
triggered.

Two facts only a local read supplies:

- **All seven files are log-normalized, not raw counts.** `arch1` values run
  0.10–4.65; `kaden25rpe1` 0.43–5.75. The four already in use are the same, so
  the frozen decomposition protocol applies unchanged. It also means **no
  public file satisfies the Arc submission's count-space requirement**; counts
  must come from `virtual_cell.arc.generate`.
- **`kaden25rpe1` matches Arc's cell-count regime**: median 400
  cells/perturbation, 919 perturbations with ≥400 cells.

## Why these cannot join the four-context tensor

Shared-perturbation counts against the four-context core (1,264 perturbations):

| dataset | shared with the core | shared with the union of four |
|---|---|---|
| `kaden25rpe1` | 113 | 235 |
| `arch1` | 17 | 50 |
| `wessels23` | 0 | 0 |

A balanced five-context tensor would hold 113 perturbations with
`kaden25rpe1`, 17 with `arch1`, and 3 with both. The four-context tensor
therefore remains the benchmark, and `arch1` is used instead as an **external**
target context: 100 of its 150 perturbations appear in no source context at
all, which is the closest public approximation to Arc's unseen-context +
unseen-perturbation regime.

## Note on the label inventory

`public_label_inventory.json` (v1, built from remote HTTP range reads) is
frozen in `arc_bridge_v1_freeze.txt` and is left untouched.
`public_label_inventory_v2_local.json` is the local rebuild and carries extra
fields — control-cell counts, expression representation, per-perturbation cell
counts — that only a local read can provide. Every Arc coverage figure the two
produce is identical.
