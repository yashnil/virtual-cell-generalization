# during the bridge.
#
#   1. Scale-calibrated conserved transfer is THE point-prediction baseline.
#      B = template + s * centre_p(A), s fitted by inner leave-one-source-out
#      on source contexts only (fitted 0.52-0.59 across folds).
#
#   2. Raw source agreement is THE final confidence statistic. No learned
#      confidence model is justified: M0 >= learned on ranking in 4/4 contexts
#      and on risk-coverage in 16/20 (context, coverage) cells.
#
#   3. NO gamma or pathway correction is currently justified. Pathway residual
#      models v1 and v2 both failed to improve outer response prediction; at the
#      theoretically correct coefficient v2 made every context worse. TERMINATED.
#
#   4. Confidence and absolute experiment-priority are DISTINCT objectives.
#      Targeting least-confident perturbations captures ~half of random error;
#      ranking by expected error magnitude captures ~twice random. Two scores,
#      two questions, never interchangeable.
